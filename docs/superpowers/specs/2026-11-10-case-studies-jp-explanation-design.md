# Case Studies 日本語解説追記 デザイン

## 1. 目的
- [CASE-STUDIES_JP.md](./../../../CASE-STUDIES_JP.md) と [case-studies/CASE-STUDY-PELOTON-FY27.md](./../../../case-studies/CASE-STUDY-PELOTON-FY27.md) に日本語解説を追記し、日本語話者がケースを実務学習・面接練習に使いやすくする。

## 2. スコープ
- 変更対象は以下の2ファイルのみ。
  - [CASE-STUDIES_JP.md](./../../../CASE-STUDIES_JP.md)
  - [case-studies/CASE-STUDY-PELOTON-FY27.md](./../../../case-studies/CASE-STUDY-PELOTON-FY27.md)
- 既存英語本文は保持し、追記で対応する。

## 3. 変更設計

### 3.1 CASE-STUDIES_JP.md
- 「Pelotonケースの読み方（実務向け）」セクションを追加する。
- セクション内容:
  - SCQAのどこを見るか
  - 論点の優先順位付け
  - 面接練習での使い方（時間配分）
  - Peloton個別ファイルへの導線リンク

### 3.2 CASE-STUDY-PELOTON-FY27.md
- 末尾に「## 日本語解説（実務向け）」を追加する。
- 追加内容:
  - SCQAの日本語解説
  - 主要論点（収益性・市場ポジショニング・資本配分・ターンアラウンド）
  - 使い方（面接練習、社内検討、提言作成）
  - よくあるミスと回避ポイント

## 4. 品質基準
- 原文の意味を変えない（既存英語本文は編集しない）。
- Markdown見出し階層を維持する。
- セクション間リンクが有効であること。
- 日本語説明は簡潔で、実務活用に直結する内容にする。

## 5. 検証方針
- 差分確認で、変更が2ファイルへの追記に限定されることを確認する。
- 目視で見出し階層（`#`/`##`/`###`）の整合性を確認する。
- 追加リンクが存在ファイルを指すことを確認する。
